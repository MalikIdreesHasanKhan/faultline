# Contributing

Contributions are welcome under Apache-2.0.

1. Create a focused branch.
2. Install with `python -m pip install -e ".[dev]"`.
3. Add or update tests for behavior changes.
4. Run `ruff check .`, `pytest`, and `python -m build`.
5. Keep catalog writes behind explicit approval and preserve failure details.

Please do not include real DataHub tokens, proprietary URNs, or incident data in
issues, fixtures, recordings, or pull requests.
